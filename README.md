Stockmarket
===========

Stockmarket is a stock market game based on the 80's board game "stockmarket!" built with golang, templ,HTMX, and PostgreSQL. You can buy and sell stocks based on random insights generated by the game. Each player gets 3 plays per round, after which the stock prices are updated according to the insights of the players.

stockmarket self hosted on my local unbuntu server using nginx, docker-compose, and docker. CI/CD is set up with a git post-recieve hook and docker-compose.

## Features

- Stocks
- Insights
- Stocks can be bought or sold
- Games can be created and played
- After each round in a game (once every player has made 3 moves) the stock prices is updated according to player insights

## Repo Structure

- controllers - contains the controllers for the routes
- router - self explanatory. contains the routes for the project
- templates - contains the templ templates for the frontend (ignore the files ending with _templ.go, those are auto generated by templ)

## Getting Started

### Prerequisites

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

### Running the project

`cd backend/`
`go run .`

postgres should be running on port 5433 (this is specified in a .env file)

### .env layout

```
JWT_SECRET=secret
PORT=4040
DB_HOST=localhost
DB_USER=me
DB_PASSWORD=password

DB_NAME=postgres
DB_PORT=5433

ENVIRONMENT=development
```

in deployment:

```
ENVIRONMENT=production
DB_HOST=db
DB_USER=postgres
```

Images are kept out of git for the skae of push/pull performance. locally these are kept at `~/Documents/Code/Decent Projects/stockmarket/backend/static/imgs` on my laptop.

### seeding

`setup.sql` contains the seeding for the database. this includes insight templates and stocks.

### logging in

Visit `stockmarket.samfelton.com/login`, and login as `user` with password `password`.

There is a game created with the gameID `game` if you would like to see the game in action.
